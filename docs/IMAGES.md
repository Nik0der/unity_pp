# Image Slots
Put your custom images into the `/public` subfolders with these paths:
- /brand/logo.svg, /brand/favicon.svg
- /hero/search-hero.webp, /hero/ingest-hero.webp, /hero/library-hero.webp, /hero/metrics-hero.webp
- /illustrations/empty-search.svg, /illustrations/empty-library.svg
- /watermarks/similarity.png
- /placeholders/thumb-fallback.png

These files are optional. If a file is missing, UI will gracefully fallback (hide image or use gradients).
